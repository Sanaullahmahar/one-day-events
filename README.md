# 🎉 One Day Event Landing Page Clone

A modern, responsive landing page inspired by the **One Day Event** website, rebuilt using **Next.js, TypeScript, and Tailwind CSS** with a custom **blue theme (inspired by Events.com)**.


---

## 📌 Project Overview

This project is a **frontend clone** of the One Day Event landing page with improvements such as:

- Clean and scalable architecture  
- Reusable components  
- Dynamic data structure (ready for backend integration)  
- Custom UI enhancements  


---

## 🛠️ Tech Stack

- ⚡ Next.js (App Router)  
- 🔷 TypeScript  
- 🎨 Tailwind CSS  
- 🧩 Component-based architecture  
- 📦 Dynamic data rendering  

---

## ✨ Features

- ✅ Fully responsive design (mobile, tablet, desktop)  
- ✅ Dynamic Hero Section (rotating insurance types)  
- ✅ Reusable UI components  
- ✅ FAQ Accordion (only one open at a time)  
- ✅ Testimonials Carousel with:  
  - Pagination dots  
  - Dynamic reviews  
  - "Read More" modal popup  
- ✅ Clean and modern UI (blue theme)  
- ✅ Scalable folder structure

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Sanaullahmahar/one-day-events.git
```

Navigate to project:

```bash
cd one-day-events
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:3000
```
